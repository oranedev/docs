## Overview

Funding for a Canadian pre-seed AI company is a **portfolio game**, not a single application. Multiple streams in parallel, systematically rotated, each requiring a different framing of the same underlying technology.

The key insight: **the same company, described differently, qualifies for different programs.**

---

## Primary Funding Sources

### [[IRAP]] — The Crown Jewel
**NRC Industrial Research Assistance Program**

- **Amount:** $50K–$1M+ non-repayable
- **Fit score for this stage:** 95%
- **What they fund:** Technological uncertainty — R&D that might fail
- **What they don't fund:** Product development, building an app, integrating existing APIs

**The critical framing shift:**

| ❌ Rejection framing | ✅ Fundable framing |
|---|---|
| "We're building a compliance dashboard" | "We're developing novel edge AI quantization techniques to run NLP models on low-power devices" |
| "We're building an app" | "We're solving an unsolved problem: 100ms latency on ARM chips with 99.9% accuracy" |

**Technical Uncertainty Criteria** (need 2 of 3):
1. We don't know if it's possible (feasibility uncertainty)
2. We're not just using APIs, we're writing new methods (technical content)
3. We're testing hypotheses, not building features (experimental process)

**The [[ITA Assignment]] is the gating step.** Industrial Technology Advisors are the gatekeepers. If they like you, they write the proposal *with* you. Every interaction with IRAP is actually relationship management with a specific ITA.

**Phase 1 target:** Accelerated Review Process (ARP) — up to $75K, fast approval (<4 weeks)

---

### [[SR&ED]] — The Retroactive Safety Net
**Scientific Research & Experimental Development Tax Credit**

- **Amount:** 35% refund on qualifying R&D spend (SR&ED + IRAP = stacked)
- **Fit score:** 90%
- **Key insight:** This is **retroactive** — you're already doing qualifying work. Start documenting now.

**Documentation habit (daily):**
```
Technical Uncertainty Addressed: [What didn't we know how to do?]
Systematic Investigation: [What experiments/approaches did we try?]
Technological Advancement: [What new knowledge was gained?]
Time Spent: X hours | Project Code: [YOUR-CODE-2026]
```

**SR&ED stacks with IRAP** — you can claim both on the same R&D activity.

---

### [[Velocity]] — The Network Accelerant
**UofT/McMaster Accelerator Programs**

- **Amount:** $100K–$500K
- **Fit score:** 85%
- **Real value beyond money:** Access to hospital networks, investor demo days, academic partnerships
- **Application timing:** Pre-orders count as traction — apply now, not after pilot

---

### [[ISC Challenges]] — The Government Contract Path
**Innovative Solutions Canada**

- **Amount:** $150K–$1M
- **Fit score:** 80%
- **Structure:** Phase 1 (feasibility, $150K) → Phase 2 (prototype, $1M)
- **Categories to monitor:** Healthcare delivery, privacy/security, medical device innovation
- **Key difference from grants:** This is a government *purchase*. They want a working thing.

## The [[10-Day Rotation Protocol]]

The system that eliminates decision fatigue. **The rotation decides focus. You execute.**

```
Day 1: IRAP       → Email ITA, draft one proposal section
Day 2: SR&ED      → Log R&D hours, document one technical uncertainty
Day 3: LSIF       → Research one eligibility criterion
Day 4: HTF        → Identify one hospital innovation lead
Day 5: Velocity   → Refine one pitch deck slide
Day 6: Mitacs     → Search for one academic supervisor
Day 7: Buffer     → Clear "Waiting on Reply" items
Day 8: ISC        → Check for new challenges, assess fit
Day 9: AI/Compute → Verify NSERC, compute credit access
Day 10: Review    → Retrospective, update risk matrix, plan next cycle
```

**Recovery rules:**
- Missed a day? Resume where you left off — don't skip, don't double up
- Rejection arrives? Open risk matrix before ruminating
- Deadline <7 days? Override rotation, enter sprint mode, resume after submission
- Hot lead? Mark ⭐, handle in Phase 4 "send slot" — do NOT disrupt rotation

## The Fundable Thesis

When pitching any program, lead with this structure:

1. **The pain** — Canadian medical practices face $100K+ fines for PHIPA violations
2. **The technical challenge** — Running high-accuracy NLP on low-power edge devices (solved, but hard)
3. **Why it requires R&D** — Model quantization at this constraint level has no existing solution
4. **Why we can do it** — Domain expertise in Ontario compliance + edge AI development track record
5. **The unlock** — If successful: new standard for medical IoT where air-gapped security meets cloud intelligence
